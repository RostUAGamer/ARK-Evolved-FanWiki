# Внесок у проект ARK: Evolved FanWiki 🦖

Дякуємо за інтерес до розвитку проекту **ARK: Evolved FanWiki**!

## Як долучитися?

### 1. Повідомлення про баги або пропозиції нових функцій
- Перевірте [список Issues](https://github.com/RostUAGamer/ARK-Evolved-FanWiki/issues), щоб переконатися, що проблема ще не обговорюється.
- Створіть новий Issue з чітким описом та кроками для відтворення.

### 2. Pull Requests
1. Зробіть Fork репозиторію.
2. Створіть нову гілку для своєї функціональності (`git checkout -b feature/amazing-feature`).
3. Внесіть зміни та переконайтеся, що тести проходять (`flutter test`).
4. Зробіть коміт (`git commit -m 'Add amazing feature'`).
5. Запуште гілку (`git push origin feature/amazing-feature`).
6. Відкрийте Pull Request до гілки `main`.

## Вимоги до коду
- Дотримуйтесь стандартних рекомендацій Dart & Flutter.
- Запускайте `flutter analyze` перед створенням PR.
