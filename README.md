# ARK-Evolved-FanWiki 🦖🦕

Енциклопедія істот та динозаврів для **ARK: Survival Evolved**, створена на **Flutter**.

## 📱 Особливості
- Довідник динозаврів та істот ARK
- Детальна інформація про приручення, харчування, сідла та корисність
- Стилізований інтерфейс у стилі голографічного HUD / Engram ARK
- Пошук та фільтрація

## 🚀 Запуск проекту
1. Переконайтеся, що встановлено Flutter SDK
2. Встановіть залежності:
   ```bash
   flutter pub get
   ```
3. Запустіть додаток:
   ```bash
   flutter run
   ```
